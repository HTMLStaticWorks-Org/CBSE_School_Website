# Greenfield International School — CBSE Website

A responsive multi-page HTML, CSS, and JavaScript website designed for a CBSE Senior Secondary School (`Greenfield International School`).

## Pages
- `index.html` — Home 1 (Centered CBSE hero, stats strip, 6-card CBSE learning pillars, highlight band, campus life grid, quote & CTA)
- `home2.html` — Home 2 (Distinct glassmorphic hero + 3-card CBSE campus spotlight, welcome panel, whole-child approach, mosaic grid, campus feature & community notes)
- `about.html` — School heritage, values showcase, core CBSE values, and campus facilities
- `academics.html` — NEP 2020 (5+3+3+4) CBSE curriculum stages from Foundational to Senior Secondary and STEM/AI labs
- `admissions.html` — 4-step CBSE admissions journey, age criteria, and enrollment document checklist
- `products.html` — Greenfield CBSE Campus Store with interactive category filters for NCERT textbook kits, school uniforms, STEM/robotics kits, lab coats, and school stationery
- `contact.html` — Admissions & campus contact details, guided visit info, transport highlights, enquiry form, and Google Maps embed
- `login.html`, `register.html`, `forgot-password.html` — Clean, centered single-card authentication pages (no navbar, footer, or imagery) with top-right theme/RTL toggles, password visibility eye toggles, Terms & Conditions agreement on registration, and centered social media sign-in options

## Run locally
Open `index.html` directly in a browser or serve the project directory with any static HTTP server.

## Features
- Centered desktop navbar links (`Home1`, `Home2`, `About`, `Academics`, `Admissions`, `Products`, `Contact`) with `Sign in` styled as a button at the end.
- Responsive tablet (`768px`) and mobile hamburger navigation containing links, Theme toggle, RTL toggle, and the `Sign in` button.
- High-contrast Royal Academic Navy, Cobalt Blue, and Warm Academic Gold palette supporting Light mode, Dark mode, and LTR/RTL persistence via `localStorage`.
- Smooth scrolling Back-to-Top button across all content pages.
- Bespoke CBSE school photography (`assets/images/`) paired with curated school, library, lab, and textbook assets.
